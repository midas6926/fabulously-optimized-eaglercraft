# Patches

This directory is a patch-ready prototype for the browser optimization subset of Fabulously Optimized.

## What is included

- `BrowserPerformanceConfig.java`
- `DynamicFpsLimiter.java`
- `EntityCullingManager.java`
- `BlockEntityOptimizer.java`
- `FastChestRenderer.java`

These are intentionally written as reusable helper classes so they can be adapted into the Eaglercraft client source tree without depending on the Fabric mod ecosystem.
